# Micro Shoe Mart Online

Create a professional, modern, premium, fully responsive e-commerce website for Micro Shoe Mart, located at RTC Busstand Road, Koilkuntla, Nandyal District, Andhra Pradesh, India – 518134, with Instagram https://www.instagram.com/micro__shoe_mart/. Build it as a real footwear shopping website, not a basic template, with a clean fashion-focused UI, smooth professional animations, excellent mobile responsiveness, fast loading, modern typography, attractive product cards, hover effects, page transitions, skeleton loaders, and polished micro-interactions. The top navigation should contain the Micro Shoe Mart logo/name, Home, Shop, Men, Women, Kids, Offers, About, Contact, Search, Wishlist and Cart, with a sticky navbar that becomes compact while scrolling. Immediately below the navbar, add a smooth continuously scrolling announcement/marquee bar for discounts, offers, new arrivals and advertisements; this content must be dynamically managed from the Admin Dashboard so the admin can add, edit, activate/deactivate and delete promotional messages without changing the website code. Create an attractive hero section with footwear imagery, headline such as “Step Into Your Style”, supporting text and Shop Now/View Offers buttons, followed by category sections for Men’s Footwear, Women’s Footwear, Kids’ Footwear, Sports Shoes, Casual Shoes, Sandals, Slippers and Formal Shoes. Create a dynamic product catalogue where every product card displays product image, name, category, original price, discounted price, discount percentage, stock status, New/Sale badges, wishlist and Add to Cart buttons, with professional hover animations. Create a detailed product page with multiple images, product description, brand, category, original price, discount price, discount percentage, available sizes, colors, stock quantity, quantity selector, Add to Cart, Buy Now and Wishlist. Add search, category, price, size, gender, discount and availability filters with sorting options such as newest, price low-to-high, price high-to-low and highest discount. Create a complete shopping cart showing products, selected sizes/colors, quantity, discounts, subtotal and total amount. For checkout, collect customer name, mobile number, WhatsApp number, delivery address, city, district and pincode, and instead of an online payment gateway, provide an “Order via WhatsApp” button that automatically generates a WhatsApp message containing the customer details, complete product list, sizes, colors, quantities, prices, discounts and final total, then opens the store’s WhatsApp chat. Keep the WhatsApp number configurable from Admin Store Settings rather than hardcoding it. Add a professional order confirmation screen with order ID, order summary, total amount and WhatsApp continuation button. At the bottom-right of the customer website, add a small subtle 👟 shoe icon that acts as hidden admin access; when clicked, open a professional PIN login modal asking for the admin PIN 4321, and after successful verification open the Admin Dashboard. Do not expose the PIN directly in frontend source code; use proper server-side authentication/authorization where supported. Build a professional Admin Dashboard with sidebar navigation for Dashboard, Products, Categories, Orders, Advertisements, Store Settings and Logout. The dashboard should show Total Products, Active Products, Out-of-Stock Products, Orders, Pending Orders and Sales, with useful charts/statistics. In Product Management, allow the admin to add, edit, delete, activate/deactivate and manage products including product name, description, category, brand, gender, original price, discount percentage, automatically calculated discount price, sizes, colors, stock quantity, multiple product images, featured status, new arrival status and sale status. Allow multiple image uploads with preview, deletion, reordering and primary-image selection. In Advertisement Management, allow the admin to create promotional messages with title, text, optional link, start/end dates, active status and display order; active advertisements should automatically appear in the scrolling announcement bar below the navbar. In Order Management, display order ID, customer details, products, quantities, sizes, total amount, date and status, with statuses such as New, WhatsApp Contacted, Confirmed, Packed, Shipped, Delivered and Cancelled. Add Store Settings where the admin can manage store name, logo, WhatsApp number, Instagram URL, address, phone, email, opening hours, delivery information and policies. Use a proper persistent database and storage, preferably Supabase if suitable, with tables for products, categories, advertisements, orders and store settings. Use React, TypeScript, Tailwind CSS and reusable components with proper validation, error handling, loading states and secure environment variables. Add a floating WhatsApp button to the customer website using the configured WhatsApp number. Create a professional footer containing the store name, tagline “Step Into Your Style”, address, navigation links, Instagram and policies. Optimize the website for SEO with proper page titles, meta descriptions, Open Graph data, semantic HTML and clean URLs. Make the entire website production-ready, mobile-first and visually impressive, with no Lorem Ipsum, fake non-functional buttons or unnecessary placeholder elements. Test all major flows including product creation/editing/deletion, image upload, discounts, search, filters, cart, checkout, WhatsApp order generation, advertisements, admin authentication, dashboard, store settings, order management and mobile responsiveness.
